Coding a village power shortage

Read the article, then code it before opening the feedback. In the annotation tool, select a passage to mark evidence, use ? for a field hint, and flag an uncertain decision for discussion.

Fictional article

In the winter of 2024, evening power cuts were common in Henan Village. Farmer Zhang San lost income whenever the cold store went dark.

State Grid installed a battery storage station to store surplus solar electricity for the evening. The cuts became shorter, but Zhang San still lost produce on two nights.

The village bulletin concluded, “The county should subsidize a second storage station. A reliable supply should be within reach of every household.”

1. Screen the article

Topical relevance / character / plot — which three codes apply?

State Grid acts in a Chinese energy transition story. Installing storage changes the duration of outages, so both character and plot are present. In the tool, answer all three screening questions and reread the article.

2. Identify ideology references

Which references can you mark?

Code Xi Jinping, Party and Western references 0. State Grid appears as a company, and the bulletin attributes no statement to Xi. Western critical positioning is inapplicable (−1).

3. Mark the starting setting

Which spans establish where and when the story begins?

The first sentence establishes the baseline. “Two nights” measures a later loss.

4. Identify characters in order

Which character cards should you create, in order of first appearance?

Henan Village is the location. Mark Zhang San (citizen, victim) and State Grid (domain, hero). Both are PRC-Chinese here. Link Zhang San to lost income and produce, and State Grid to installing storage. Two characters have clear roles.

5. Classify the plot

How does the story end?

“The cuts became shorter” is a gain, but Zhang San “still lost produce.” Mark those passages and choose Mixed (3). The proposed second station has yet to solve the problem.

6. Code the moral

Which moral types appear in the conclusion?

The subsidy is a policy recommendation. Reliable supply for every household expresses a value. Mark the two sentences separately and code moral present, policy and value all 1.

7. Mark the technology

Which phrase names a specific technology used as a transition solution?

The battery storage station moves surplus solar electricity into the evening. Mark it and code technology 1.

8. Draft the narrative summary

Compare with a model summary

In Henan Village in the winter of 2024, Zhang San lost income during power cuts. State Grid installed battery storage and shortened the cuts, but Zhang San still lost produce. The bulletin calls for a subsidy for a second station and reliable electricity for every household.

Try it in the annotator

If a coder calls the plot positive, select “still lost produce” and choose Flag for discussion. Ask whether the loss was resolved by the end.
